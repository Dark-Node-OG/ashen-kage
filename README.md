# ASHEN KAGE

A dark, cinematic 2.5D atmospheric puzzle-platformer by **Dark Node**.

A tiny figure carries one small light through a huge, beautiful, dying world.
The player is not powerful. The world is the challenge. You learn, you fail,
you understand, you improve — and eventually you reach the end.

**Free to play. Works offline. Runs in any modern browser, on desktop or phone.**

---

## Play

- **Desktop:** move `A` / `D` (or arrows), jump `W` / `Space`, crouch `S`,
  grab & pull levers / boxes with `J`, pause `Esc`.
- **Phone (landscape):** analog stick on the left, `JUMP` and `GRAB` buttons on the right.
- Swing on ropes, push a boat into the water and sail across, time the crushers,
  cross collapsing floors, and dodge the bear traps.

## Chapters

I. The Fallen Village · II. The Black Forest · III. The Drowned Temple ·
IV. The Siege · V. The Forgotten Castle · VI. The Ashen Mountain · VII. The Shadow

The story ends. The mastery does not — Ashen Trials and New Journey+ unlock after the finale.

## Tech

Pure web: HTML5 Canvas + vanilla JavaScript modules. No build step, no backend.
Progress is saved locally in the browser. Offline support via a service worker (PWA).

## Run locally

```
python serve.py
```
then open http://127.0.0.1:8900/ (this dev server disables caching so you always get fresh files).

## Deploy

It is a static site — just host the folder. GitHub Pages or Netlify both work, free.
No database or server is needed.
